Pina Viewer for macOS

次の本まで、キーひとつ。

キーボードで操る、画像と漫画のためのビューアです。フォルダか書庫を開けば、もう読めます。ライブラリを作る手間も、取り込みもありません。↑↓ で本を移るので、全画面のまま、フォルダの木をまるごと一続きに読み進められます。

Mac 版をダウンロード Homebrew で入れる

無料macOS 13 以降Apple シリコン・Intel 両対応署名・公証済み

本棚、本、ページ。

たいていのビューアは、次の本を開くたびに Finder へ戻らせます。Pina Viewer は戻らせません。フォルダや書庫が 1 冊の本で、そのすぐ下にある画像と動画がページです。本棚は開いた場所から割り出すので、矢印キーはいつも筋の通った動きをします。

静止画も動画も、1 冊の中に順に並びます。

←→ でページをめくる。動画も含めて本の中をすべて順にたどります。矢印キーの意味が途中で変わることはありません。

↑↓ で本を替える。第 02 巻を読み終えたら、第 03 巻はキーひとつ先。フォルダでも書庫でも同じです。

整理するためではなく、読むために。

動画もページのひとつ

静止画と動画が混ざったフォルダも、そのまま読めます。サムネイル一覧では、動画にもほかのページと同じように表紙のコマが付きます。

見開きは右綴じも左綴じも

漫画は漫画らしく読めます。表紙のせいで組み合わせがずれたら、1 ページぶん送って組み直せます。

書庫をそのまま開く

zip・cbz・rar・cbr・7z・cb7、それに PDF。展開したファイルをディスクに残しません。

ネイティブで小さい

約 1.6 MB のユニバーサルアプリで、署名・公証済み。Electron も常駐プロセスもテレメトリもありません。

設定は読めるファイルひとつ

キーの割り当ても含め、設定はすべて ~/.config/pina-viewer/settings.json にあります。キーを整列した素の JSON なので、そのまま dotfiles に入れられます。

キーは自分好みに

割り当てはすべて設定画面から変えられます。アプリの中で ? を押せば一覧が出ます。

見方はひとつではない。

スライドショーページを自動でめくります。スクロールかフェードを選べます。

整理1 枚ずつ見ながら捨てるものに印を付け、最後にまとめて削除します。

対応形式

画像jpg jpeg jpe jfif png gif webp heic heif avif bmp tif tiff tga
動画mp4 m4v mov
書庫zip cbz rar cbr 7z cb7
文書pdf

AVFoundation で再生できない形式（avi・mkv・webm・wmv・flv）も、一覧には出します。再生はしませんが、何があるかが見えるので、消えたと戸惑わずに変換へ回せます。設定で隠すこともできます。

インストール

macOS 13（Ventura）以降で動きます。無料です。

Homebrew で入れる

ターミナル
brew tap ayrapps/tap
brew trust ayrapps/tap
brew install --cask pina-viewer

Homebrew 6 以降では、第三者の tap に brew trust が必要です。これが無いと “Refusing to load cask from untrusted tap” で止まります。

更新は brew upgrade で届きます。

zip を落として入れる

  1. 最新版をダウンロードする。
  2. 展開する。
  3. Pina Viewer.app を /Applications へ移す。
