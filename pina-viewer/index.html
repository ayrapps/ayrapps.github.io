Pina Viewer for macOS

The next book is one key away.

A keyboard-driven image and comic viewer. Point it at a folder or an archive and read. There is no library to build and nothing to import — and ↑↓ move between books, so a whole folder tree reads as one continuous thing without ever leaving full screen.

Shelf, book, page.

Most viewers send you back to the Finder to open the next book. This one doesn’t. A folder or an archive is a book; the images and videos directly inside it are its pages. The shelf is worked out from where you opened, so the arrow keys always mean something sensible.

Pages in Vol. 02←→

Stills and clips in one book, in order.

←→ turn pages. Through everything in the book, videos included — the arrow keys never change meaning under you.

↑↓ change books. At the end of Vol. 02, Vol. 03 is one key away — folder or archive, it doesn’t matter.

Made for reading, not managing.

Videos are pages, not a separate mode

A folder holding both stills and clips just works. A video gets a poster frame in the thumbnail grid like any other page.

Two-page spreads, right- or left-bound

Manga reads the way it should, and you can nudge the pairing by one page when a cover throws it off.

Archives open directly

zip, cbz, rar, cbr, 7z, cb7 — and PDFs. Nothing is permanently unpacked to disk.

Native and small

About 1.6 MB, universal, signed and notarized. No Electron, no background daemon, no telemetry.

One readable settings file

Everything, key bindings included, lives in ~/.config/pina-viewer/settings.json. Plain JSON with sorted keys — it can go straight into your dotfiles.

Every key is yours

Every binding can be changed in Settings. Press ? in the app for the full list.

More than one way to look.

Formats AVFoundation cannot play — avi, mkv, webm, wmv, flv — are listed but not played, so you can see what is there and convert it rather than wonder where it went. They can be hidden in Settings.

Install

Requires macOS 13 (Ventura) or later. Free.

With Homebrew

Terminal
brew tap ayrapps/tap
brew trust ayrapps/tap
brew install --cask pina-viewer

brew trust is required for third-party taps on Homebrew 6 and later; without it the install stops with “Refusing to load cask from untrusted tap”.

Updates come with brew upgrade.

Or download the zip

  1. Download the latest release.
  2. Unpack it.
  3. Move Pina Viewer.app into /Applications.
